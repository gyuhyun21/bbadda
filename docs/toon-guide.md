참고: 육아부부의 사야이(다음, 사회인 야구 생활툰), 생활의 참견(네이버). 그림·문장은 옮기지 않고 연출 방식만 배운다.

## 2. AI 티를 줄이는 대본 규칙
1. **설명하지 말고 보여 준다.** 아빠의 강의 대신 상황·사고·딴지로 정보를 흘린다. 정보는 엄마나 세이의 한마디, 또는 짧은 내레이션 박스에 맡긴다.
2. **대사는 짧게.** 한 줄 15자 안팎, 한 컷에 0~2개. 대사 없는 컷을 화마다 1개 이상 둔다.
3. **내레이션은 끊어서 뜸 들이기.** "투수, 던졌습니다!" → "타자의 선택은…" → "공은…"처럼 한 박자씩 나눈다.
4. **결말은 교훈 금지.** 끝에서 두 번째 컷에 웃음(펀치라인), 마지막 컷은 툭 던지는 한마디·반전·여운.
5. **생활 디테일을 꼭 하나.** 아이폰 알림, 단톡방, 중고 거래 앱, 치킨 쿠폰, 학원 숙제, 무릎 같은 구체적인 물건·상황.
6. **금지 표현:** "좋은 질문이다", "~했구나…", "미안하다, 얘들아", "모두가 행복했다", "알고 보니", 감정을 직접 말하는 내레이션.
7. **고증 체크:** 연도에 맞는 물건(2017년 = 스마트폰으로 기사 확인), 장소, 기록. 기록·역사·규칙은 출처를 확인하고 마지막 장에 적는다.

## 3. 연출 규칙
- **구도를 섞는다:** 10컷 중 와이드(배경 전체) 2, 미디엄 4, 익스트림 클로즈업(눈·손·공·폰 화면) 2, 반응 컷 1, 무대사 컷 1.
- **표정을 컷마다 다르게:** 컷 목록에 인물별 표정 번호(표정 시트)를 적고, 같은 표정은 연속으로 쓰지 않는다. 화마다 SD(꼬마) 데포르메 컷 1개.
- **효과음 글자**(딱!, 탕, 쿵, 팔짝)는 코드로 크게 얹는다. 그림 안에는 글자를 넣지 않는다.
- **카드 구성을 바꿔 가며:** 한 장에 큰 컷 1개 / 위아래 2컷 / 내레이션만 있는 흰 카드(시간 경과·뜸 들이기).
- **회상**은 색을 바래게(세피아·망점), **실제 사진**이 필요하면 사이트 화면·직접 찍은 사진만.

## 4. 만드는 순서
1. 주인 줄거리 → Claude 가 **비트 표**(상황·반전·펀치라인)와 **컷 목록**(카드 번호·구도·인물·표정·대사·효과음)을 만들어 주인 확인
2. 컷 그림 생성(gpt_image_2_5 medium, 컷당 0.5 크레딧, 화당 4~5 크레딧)
3. `build_ep.py` 로 카드(말풍선·내레이션·효과음 얹기) → 미리보기 → 주인 확인 → 게시
