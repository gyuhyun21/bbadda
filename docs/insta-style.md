# 인스타 게시물·릴스 지침 (2026-10-26 개편)

주인 결정(2026-10-26): 정해 둔 연출 규칙 때문에 반응이 약했다. 연출(후킹 모양·장면 수·길이·구성)은 고정 규칙 대신 **비슷한 계정에서 반응이 터진 형식을 참고해** 매번 고른다(`docs/insta-swipe.md`, 스킬 `ig-viral`).
의무는 1절(지키는 원칙)·3절(문장)·4절(목소리·숫자 읽기)뿐이다. 나머지는 참고.
자동 카드(`scripts/insta/build.ts`), 루틴의 hook_ko·ig 문구, 릴스(`docs/reel-routine.md`) 모두 이 문서를 따른다.

## 0. 발행 횟수(2026-10-26 주인)
- 피드(카루셀) 하루 1번: 밤판. 콘텐츠가 main 에 머지되면 `ig-auto.yml` 이 자동 게시한다(아침·오후 세트는 수동 실행으로만). 되돌리기: 저장소 변수 `IG_FEED_KINDS='morning afternoon night'`.

- 승부 예측(사이트 투표)은 인스타에서 유도하지 않는다(주인: 사용자가 적고 들어올 유인이 안 된다). 사이트 기능은 그대로 둔다. 댓글 질문은 경기·선수 이야기로.

## 1. 지키는 원칙(의무, 변하지 않음)
- 사실은 기사·`data/postseason.yaml`·사이트 요약으로 확인된 것만. 진행 중 경기 점수처럼 바뀔 수 있는 숫자는 넣지 않는다.
- 기사 문장 15단어 넘게 옮기지 않기, 경기 영상·보도 사진·구단 로고 쓰지 않기, 응원가 음원 쓰지 않기.
- 참고 계정의 대본·영상·그림은 가져오지 않는다. 빌리는 것은 형식(후킹 모양·길이·장면 전환·끝맺음)뿐이고, 어디서 빌렸는지 PR 본문에 적는다.
- 과장 후킹이라도 거짓은 금지. 루머 단정·비하·경품·대가형 문구("댓글 남기면 보내 드려요") 금지.

## 2. 스킬(`.claude/skills/ig-*`)
출처: https://github.com/Jakeschincariol/instagram-agent-skill (MIT, 2026-09-13 판, `.claude/skills/ig-LICENSE.txt`). 13개 중 7개만 넣었다: ig-viral(참고 파일), ig-reel(릴스 대본), ig-human(문장 점검), ig-caption, ig-carousel, ig-audit(지난 게시물 돌아보기), ig-plan.
- 스킬이 말하는 파일은 저장소 안에서 읽고 쓴다: `~/.claude/instagram/voice.md` → `docs/insta-voice.md`, `swipe.md` → `docs/insta-swipe.md`, `log.md` → `media/insta/reel-log.md`. plan.md 는 만들지 않는다.
- `hookscore.py`·`beats.py`·`caption.py` 는 영어 띄어쓰기 기준이라 한국어에 쓰지 않는다(2026-10-26 확인: 한 문장을 1단어·0.4초로 계산). 후킹 점수는 ig-reel 의 다섯 기준(길이·구체성·걸린 것·앞에 두기·말 거는 대상)으로 직접 매기고, 길이는 목소리 파일로 잰다.
- `python3 .claude/skills/ig-human/humanize.py <파일> --report` 는 쓴다. `slop.json` 에 한국어 번역투 표시(ko-*)를 더해 두었다. 표시된 문장은 손으로 고친다.
- 스킬의 '사용자에게 묻기·확인 받기' 단계는 자동 루틴에서는 건너뛰고, 고른 이유를 PR 본문에 적는다. 게시는 워크플로가 한다.

## 6. 자동 카드(밤판, `scripts/insta/build.ts`)
- 오늘 경기 결과가 있으면 점수 첫 장 → 경기 기록 → 승부처 → '오늘의 야구' 소식 카드(장당 3건, 최대 6장) → 빠따닷컴.
- 없으면 소식 수 첫 장(밤 hook_ko, 없으면 첫 소식 한 줄) → '오늘의 야구' 카드(장당 3건, 최대 8장) → 빠따닷컴. 본문(캡션)에도 소식 전부를 한 줄씩 적는다.
- 화면: 어두운 배경 위 흰 글씨, 강조는 노랑(#FFD43B) 또는 팀 컬러, 제목 굵게(900)·`word-break: keep-all`. 스토리는 세트마다 1장(첫 장을 세로로).
- 본문(캡션): 첫 줄이 피드에 보이는 전부다(약 125자). 끝에 질문 1줄 + "👉 프로필 링크 bbadda.com" + 해시태그 5~7개.
